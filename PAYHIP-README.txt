Wi-Fi Guard for Windows

Choose the executable that matches your Windows system:

- windows-x64\Wi-Fi Guard.exe: for 64-bit Windows.
- windows-x86\Wi-Fi Guard.exe: for 32-bit Windows, and also compatible with 64-bit Windows.

To check your system type, open Windows Settings > System > About and look for
"System type".

Run the selected executable and approve the Windows administrator prompt. The
app needs administrator permission to add or remove Windows Wi-Fi block
filters. It does not need to be installed.

The x86 and x64 executables target Windows 7, 8, 10, and 11. Windows 7 requires
Service Pack 1 and applicable platform updates. The builds have not been
runtime-tested on every listed Windows version.
